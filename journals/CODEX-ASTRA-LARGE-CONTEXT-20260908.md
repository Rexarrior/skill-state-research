# Astra: отдельная серия с большими лимитами

Статус на момент записи: серия запущена 2026-09-08 в 15:27:42 UTC
(18:27 по Москве). Итогов пока нет.
Актуальное состояние — в [run.json](../experiments/codex-astra-large-context-20260908/run.json).

По просьбе пользователя проверяем, что изменится, если почти убрать нашу
дополнительную обрезку state и observations. У четырёх ограничений теперь
значение 2 MiB: state, принимаемый input действия, сохраняемый input и result.
Остальное — как в чистой Astra: Native/Paper/V2/V3, по пять повторов пяти задач,
k=3, medium, таймаут 15 минут и максимум пять основных CLI одновременно.

Это не общий лимит промпта в 2 MiB. Комментарий остаётся ограничен 1 KiB;
штатные ограничения инструментов и провайдера не менялись.
Также сохранён целый JSON перехода при записи в историю: прежняя повторная
обрезка tool output могла разрезать большой контейнер. Native эта поправка
не затрагивает. Поэтому серия проверяет совместный эффект больших лимитов
и защиты контейнера, а не каждый фактор по отдельности.

Старые исходники и бинарник не изменены. Отдельная сборка сделана в detached
worktree поверх 85630a5b; все четыре режима используют её.
SHA-256 новой сборки: 6c573e7f919cce1968def7ec067afbcdf3f2b4a76c7811178ac5715ac84997ee.
Code Mode companion остался прежним, его отпечаток проверен.

Перед запуском прошли 18 проверок ядра, 7 доступных CLI-проверок, 13 проверок
оркестратора, штатный форматтер и doctor. Один новый CLI-тест большого shell
output оставлен явно недоступным на этом хосте: managed approval service
отклонил команды mock-provider. Это не зачтённый успех. Большой обычный
результат проверен через ActionOutcome/историю/provider_input в ядре,
а большой state и validation feedback — через запросы настоящего CLI
к локальному mock-provider.

Перед первым модельным запросом заморожены 45 файлов и расписание.
Временно перемещены 18 глобальных источников; предусмотрен проверяемый возврат
после остановки воркеров. Начальные записи первых пяти сессий показывают
gpt-6-astra без маркеров каталога скиллов и глобального профиля.
Числа по качеству и экономии до завершения серии не выводим.
