# Дополнение: обрезка наблюдений и расширенные лимиты

2026-09-09. В статье после первого блока Astra добавлены три небольших раздела:
почему короткие preview и result могли мешать проверке кода, новая Astra и новая Sol.
В обоих результатных разделах — таблица и график input, циклов и наблюдаемого времени.
Прежние восемь рисунков и результаты не заменены. Всего описано 720 исходов на тех же пяти задачах.

Источник — [отдельный пакет 200 новых сессий](../../experiments/codex-large-context-comparison-20260909/README.md).
Основной input сверён с usage каждого ответа. Дополнительный CLI delete аудит выполнен на всех
40 CLI-проектах и изменил один балл Sol/Native: полный успех 24/25 вместо исходных 23/25.
В статье это оговорено, исходные оценки сохранены в пакете. Новых вызовов моделей не было.

Уточнены методика и итоговые размышления: результат Astra с прежними лимитами не переносится
на расширенные; новая серия не изолирует вклад каждого из четырёх ограничений и защиты JSON.
Отмечены фактические размеры состояния/наблюдений, сохранённые инструментальные лимиты и
отсутствие оснований для общего ранжирования качества по нескольким исходам.

## Графики и проверка

```sh
uv run --offline --with matplotlib python articles/update-20260909/build.py
bun experiments/codex-large-context-comparison-20260909/verify.ts
bun articles/update-20260909/verify.ts
```

`build.py` адаптирован из предыдущего дополнения и создаёт только два новых PNG/SVG.
Точка — среднее пяти проектов одного повтора; черта — среднее пяти повторов.
Все исходы включены, повтор с таймаутом отмечен треугольником. Шкалы общие у двух новых
графиков, но отличаются от предыдущей пары; это отдельно сказано под рисунком в статье.
Две PNG просмотрены визуально: подписи читаются и не перекрываются.

`verify.ts` сверяет новые таблицы, точки, отпечатки всех десяти рисунков, сохранение старых
таблиц и локальные ссылки. Результат записывается в `verification.json` рядом со скриптом.
Публичный экспериментальный снимок имеет отдельный manifest; исторические снимки не переписываются.
Это редакционное дополнение, не публикация на внешней площадке и не научная валидация причинности.
