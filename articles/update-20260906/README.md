Четыре парных рисунка и общий рисунок показывают input и обращения к модели рядом.
Общий сохраняет четыре режима и нормировку input к Native; прежний рисунок только с input также сохранён.
Отдельный рисунок повторов показывает средние на задачу для каждого из десяти полных повторов:
input, обращения и фактические минуты. Все исходы включены; таймауты отмечены.

Мотивация V3 — попытка уменьшить число циклов за счёт нескольких действий. Вывод согласован с данными:
в первых трёх попытках Sol обращения сократились на 2,9%, в последующих десяти выросли на 24,3% к V2.
Циклы не подменяют фактическое время, а пакет изменений V3 не объявляется чистой абляцией батчинга.

Вводная дополнительно раскрывает последовательность: знакомая по опыту идея → перенос общей архитектуры
на разработку проектов в OpenCode/Codex → собственные изменения. Раздел об оригинале отделяет общую
концепцию от специализированного coding harness, сохраняя упоминание авторских CTF и симуляции репозитория.
Наши прогоны обозначены как перенос в другой сценарий, а не воспроизведение авторских бенчмарков.

```sh
uv run --offline --with matplotlib python articles/update-20260906/build.py
bun articles/update-20260906/verify.ts
```

Старые benchmark-проверки фиксируют состояние на момент окончания прогонов. Их хеши статьи намеренно
не переписаны: после разрешённого автором редактирования этот старый защитный тест сообщает о её изменении.
Новая проверка разрешает изменения только текста статьи и articles/README.md среди защищённых ранее файлов,
проверяя неизменность остальных исходников, журналов, данных и прежних рисунков. Она также сверяет обе
таблицы старой серии и новую таблицу, значения всех 40 точек повторов и локальные ссылки.
