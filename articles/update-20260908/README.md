# Дополнение статьи: чистые серии Sol и Astra

Два новых раздела с отдельными таблицами и графиками добавлены без замены шести прежних рисунков.
Всего в статье восемь рисунков и четыре раздельных набора: 120 + 200 + 100 + 100 исходов.
Это повторы тех же пяти проектов, не 520 разных задач.

Источник новых таблиц и рисунков — [пакет 200 новых сессий](../../experiments/codex-clean-comparison-20260908/README.md).
Точка на рисунке — среднее пяти задач одного повтора, черта и число — среднее пяти таких повторов.
Треугольник отмечает наличие таймаута; шкалы соответствующих панелей одинаковы для обеих моделей.
Основной input не включает отдельного permission reviewer, а время включает ожидания.

```sh
uv run --offline --with matplotlib python articles/update-20260908/build.py
bun articles/update-20260908/verify.ts
```

build.py пишет только два новых рисунка в PNG/SVG и figure-data.json с точками и отпечатками.
Исходники старых графиков не запускаются. В тексте сохранена авторская манера; вывод о короткой
траектории Astra отделён от гипотез о причинах и не переносится на ещё не проверенные длинные задачи.
Квадратичная оценка относится к суммарному input без сжатия истории, не к длине одного запроса
и не к стоимости. Линейная оценка требует ограниченного state/наблюдений и сама по себе
не гарантирует одинакового числа шагов.
