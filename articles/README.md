и их скрипт `experiments/article-20260904/plot.py` сохранены без изменений.

Технический текст рассчитан на Хабр или блог. Относительные ссылки работают внутри репозитория; при переносе текста
на внешнюю площадку их нужно заменить ссылками на соответствующие файлы опубликованного репозитория. Иллюстрацию
следует загрузить в редактор площадки вместе с подписью и обозначениями неудачных запусков.

Подробное описание экспериментов и проверка реализации оформлены раскрывающимися блоками
`<spoiler>` по [разметке Хабра](https://habr.com/ru/docs/help/markdown/), с пустыми строками вокруг содержимого.
Заголовки разделов остаются видимыми. В обычном Markdown-просмотрщике сворачивание может не поддерживаться.

LinkedIn-пост — самостоятельный короткий текст первой редакции, без новой серии из 200 запусков,
со ссылкой на репозиторий. После публикации большого материала
ссылку можно заменить адресом статьи. Unicode-стилизация не требуется.

Это подготовленные материалы, а не автоматически опубликованные посты. Публикация от имени автора и отправка
изменений в GitHub выполняются только по отдельному запросу.
