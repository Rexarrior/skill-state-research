# Paper2 с малыми лимитами — дополнение к статье

Добавлены 50 новых исходов (25 Sol, 25 Astra), две таблицы и два графика сравнения с большим Paper2.
Всего в статье 820 итоговых исходов на пяти спецификациях; пять технически прерванных попыток
большого Paper2 по-прежнему учтены отдельно, не подставлены в эту серию.

Источник: [отчёт](../../experiments/codex-paper2-small-context-20260910/REPORT.md),
[агрегаты и повторения](../../experiments/codex-paper2-small-context-20260910/statistics.json).
Малые лимиты: 32/64/3/4 КиБ; защита JSON сохранена. Контрольные большие результаты — из предыдущей
серии, без новых вызовов моделей. Аудит удаления на копиях всех десяти CLI-проектов не изменил оценки.

В тексте уточнены методика, хронология исправлений, сводные выводы и рассуждение о длине задачи.
Разделены качество кода, принятие finish и таймауты: Astra получила 200/200 проверок,
но ни разу не предложила finish. Частые усечения не выдаются за доказанную причину всех циклов.
Раскрыто совпадение начала прогона с очисткой кэша сборки и возможное влияние на время.
Все 12 прежних графиков сохранены; новые используют одинаковые шкалы для двух моделей.

Пересборка графиков без обращения к моделям:

```sh
uv run --offline --with matplotlib python articles/update-20260910-small/build.py
bun articles/update-20260910-small/verify.ts
```

[Проверка](verification.json) сверяет исходные хеши, оценки, агрегаты, все 20 точек новых графиков,
таблицы статьи, 12 старых рисунков и локальные ссылки. Оба новых PNG просмотрены визуально:
заголовки и легенды читаемы, панели не перекрываются. Проверки прежних редакций сохраняют свои
исторические требования к числу запусков; для текущего текста используется этот скрипт.
