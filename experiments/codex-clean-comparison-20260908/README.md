## Что опубликовано

[data.json](data.json) содержит результаты всех сессий, исходные проверки, завершение,
таймауты, счётчики и относительные пути архивов проектов. [usage-records.json](usage-records.json)
сохраняет числовые записи каждого основного обращения, чтобы независимо пересчитать расход.
[Вспомогательные вызовы](auxiliary-usage.json) не смешиваются с основным циклом.

В папке artifacts сохранены созданные проекты: после исходного внешнего оценщика и до
дополнительной CLI-проверки. [Manifest архивов](archive-manifest.json) фиксирует каждый файл
и исключения: ссылки, зависимости, кэши и возможные файлы авторизации не копировались.
Это не новые генерации и не исправленные версии кода.

[Проверка CLI delete](taskboard-delete-audit.json) выполнена на отдельных копиях всех 40 новых
CLI-проектов. Она не изменила исходные оценки: 38 прошли оба критерия, два не прошли оба.
[Сводки и точки рисунков](statistics.json) учитывают все исходы, включая таймауты.

Сырые промпты, рассуждения и вывод инструментов намеренно не экспортируются. Они остались
локально в игнорируемых .private каталогах исходных серий. [source-hashes.json](source-hashes.json)
хранит их отпечатки и происхождение, а не содержимое. [Аудит стартового контекста](initial-context-audit.json)
публикует только роли, размеры, отпечатки и проверяемые флаги. Нулевые флаги — не доказательство
полной изоляции ОС или отсутствия любых сторонних влияний.

## Проверки и воспроизведение анализа

Новых вызовов моделей при подготовке этого пакета не было. Исторические manifests и отчёты не переписаны.

```sh
bun experiments/codex-clean-comparison-20260908/verify.ts
bun articles/update-20260908/verify.ts
```

capture.ts и auxiliary.ts требуют локальных сырых журналов и отказываются перезаписывать
существующий снимок. Для повторного вычисления агрегатов из публичных данных есть analyze.ts;
проверка целостности после него должна остаться зелёной. audit-taskboard-delete.ts запускает
только созданный CLI на отдельных копиях, а не модели; её результат уже сохранён.
Ни один из этих скриптов не должен использоваться для переписывания прежних экспериментальных пакетов.

В обеих новых сериях глобальные источники восстановлены. У Sol журнал guard содержит
5250 проверок, у продолжения Astra — 3089; опасных повторных появлений источников не зафиксировано.
Выключенный скрытый кэш .system допускается только по проверенному исключению загрузчика.
