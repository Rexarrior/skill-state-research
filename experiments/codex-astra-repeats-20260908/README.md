# Codex / Astra, пять повторов

Запущена отдельная серия: Native, Paper, V2 и V3, по пять повторов пяти прежних проектов.
Всего запланировано 100 сессий, до пяти основных CLI одновременно, `gpt-6-astra`, medium, k=3.
Условия зафиксированы в [протоколе](PROTOCOL.md). Старт: 2026-09-08, 05:12 UTC. Этот документ не является отчётом о завершённом эксперименте.
Текущее состояние сохраняется в `run.json`; `bun experiments/codex-astra-repeats-20260908/progress.ts`
показывает ход серии и метаданные текущих сессий без вывода содержимого промптов.

## Подготовка

Используется прежний бинарник Codex и его Code Mode companion, с проверкой SHA-256.
[Локальная копия runner](runner.ts) сохраняет оценщик и контракт запуска, меняя только пути,
имя модели по умолчанию и отключая проектные инструкции. Глобальные скиллы на время серии
перемещаются в приватное хранилище с журналом восстановления. Сами файлы не удаляются.
Глобальные `AGENTS.md` читаются этой сборкой отдельно; пользователь согласовал их временное перемещение вместе со скиллами.

Подготовительные проверки без вызова модели:

```sh
bun test ./experiments/codex-astra-repeats-20260908/isolation.test.ts
bun experiments/codex-astra-repeats-20260908/runner.ts doctor
```

Запуск (согласие на перемещение инструкций и параллельность 5 получено):

```sh
bun experiments/codex-astra-repeats-20260908/run.ts --with-global-instructions
```

Повторный запуск поверх существующего `run.json` запрещён. Ошибки связи, лимиты и загрязнение
стартового контекста останавливают выдачу следующих задач; обычные ошибки кода и таймауты остаются исходами.

## Восстановление

Нормальный выход и обрабатываемые сигналы возвращают перемещённые источники автоматически, после остановки всех воркеров.
После перезагрузки или SIGKILL нужно прочитать **только путь** из `.private/isolation.json`
и передать его в `bun isolation.ts restore ABSOLUTE_LEDGER_PATH`. Отпечатки восстановленных файлов проверяются;
каталоги, созданные другими приложениями во время серии, сохраняются отдельно, а не перезаписываются.

`.private/` не входит в Git. Исходные трассы нельзя публиковать без отдельной проверки и редактирования
приватного контекста. Прежние отчёты, снимки и очищенные исторические журналы не пересчитываются.

## Что добавить после завершения

Отдельный отчёт с исходными и спецификационно-корректными оценками; архивы проектов; проверка контекста
и расхода; отдельный график input / обращений / наблюдаемого времени; мини-раздел статьи.
Каждая точка графика — среднее по пяти задачам одного повтора, не новая независимая задача.
Сравнение Astra с исторической Sol остаётся наблюдательным: кроме модели изменились контекст хоста,
дата запуска; фактическая загрузка может отличаться при одинаковом верхнем пределе в пять процессов. По этой серии нельзя выделить причинное влияние «интеллекта» модели.
