# Codex / Sol без глобальных скиллов

Новая серия по образцу завершённой чистой Astra: Native, Paper, V2, V3,
по пять повторов пяти проектов — 100 сессий, до пяти основных CLI одновременно.
Модель `gpt-5.6-sol`, medium, k=3. Условия — в [протоколе](PROTOCOL.md).
Прежние результаты Sol и Astra не заменяются и не пересчитываются.

Серия запущена 2026-09-08 в 10:58 UTC (13:58 МСК): перемещены 18 глобальных источников,
выданы первые пять сессий. Подготовительные тесты — 12/12, doctor и проверка отпечатков
пройдены. Это запись о запуске, не итоговый отчёт; актуальное состояние — в `run.json`.

Подготовительные проверки не вызывают модель:

```sh
cd experiments/codex-sol-clean-20260908
bun test ./contract.test.ts ./isolation.test.ts ./isolation-guard.test.ts ./pool.test.ts
bun runner.ts doctor
```

Запуск из корня исследовательского репозитория:

```sh
bun experiments/codex-sol-clean-20260908/run.ts --with-global-instructions
```

Повторный запуск поверх существующего состояния запрещён. `run.json` хранит расписание
и исходы; `source-manifest.json` фиксируется до первого вызова модели.
`bun experiments/codex-sol-clean-20260908/progress.ts` показывает метаданные основных
сессий и флаги стартового контекста без раскрытия содержимого промптов.

Глобальные источники временно перемещаются с журналом и проверкой отпечатков.
После нормального завершения и обрабатываемых сигналов они возвращаются автоматически,
только когда все воркеры остановлены. `.private/isolation.json` содержит приватный путь
к журналу для восстановления после перезагрузки или SIGKILL:
`bun isolation.ts restore ABSOLUTE_LEDGER_PATH`. Не запускайте вторую изолирующую серию параллельно.

Сырые результаты и служебные пути остаются в `.private/`, вне Git.
Завершение подтверждается `run.json`, `restoration.json` и `isolation-watch.json`,
а не наличием готового кода после таймаута. Итоговый отчёт оформляется отдельно после проверки данных.
