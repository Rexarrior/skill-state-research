# Codex / Sol: native и paper, по десять повторов

Продолжение серии V2/V3 от 2026-09-06 по прямому запросу пользователя. План фиксируется до новых вызовов.

- Десять полных повторов пяти прежних задач для native и paper: 100 новых запусков, 50 на режим.
- Модель gpt-5.6-sol; reasoning medium; 15 минут на задачу. Максимум пять основных CLI одновременно:
  пять внешних runner с внутренней конкурентностью 1. Вспомогательные вызовы внутри CLI считаются отдельно.
- Native — baseline-режим того же исследовательского бинарника, штатные transcript и Code Mode.
  Paper — ранее проверенная реализация статьи, один шаг и последнее наблюдение. k=3 относится только
  к уже завершённым V2/V3; native/paper этот параметр окна не используют.
- Бинарник, companion Code Mode, исходники, промпты, спецификации и оценщик сверяются с предыдущей серией.
  Окружение не очищается и не перенастраивается: тот же профиль, sandbox и разрешения.
- Пустые отдельные рабочие каталоги. Неудачи, таймауты и отказы сохраняются, автоматических перепрогонов нет.
- Нечётные полные повторы начинают с native/paper, чётные с paper/native; штатный runner чередует порядок
  по проектам. Это чередование, не рандомизация. Новые повторы не назначаются по промежуточным результатам.
- Оценщик остаётся неизменным. Уже известное лишнее требование reply.id в тесте удаления CLI разбирается
  отдельно: дополнительная проверка на копиях всех 20 новых CLI-проектов, исходные баллы сохраняются.
  В сводке четырёх режимов одинаково показываются исходный и скорректированный срезы.
- Основной input включает кэшированный вход и сверяется с usage-журналами; output и обращения считаются
  отдельно. Связанный вспомогательный usage не смешивается с основным и не переводится в деньги.
- Для native завершение определяется штатным terminal event, а не наличием skill_step/finish.
  Для paper требуется принятый finish. Качество артефакта и завершение агента показываются раздельно.
- Новые данные объединяются для сравнения с 100 завершёнными V2/V3-запусками, без их изменения.
  Матрица содержит 4 режима × 10 повторов × 5 задач = 200 исходов, но только пять разных задач.
- Native/paper запускаются позже V2/V3. Номера повторов не означают синхронные seed-matched пары:
  нельзя выдать сводку за рандомизированный одновременный четырёхсторонний эксперимент.
  Сравнение имеет одинаковые настройки, но сохраняет временной confound и различия упаковки инструментов.
- Статья, её данные, предыдущая серия V2/V3 и все её журналы защищаются хешами. Новые отчёты живут здесь.
