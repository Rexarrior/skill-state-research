# Paper2 с прежними малыми лимитами

Зафиксировано до запусков. 50 сессий: Sol и Astra, по пять повторов пяти прежних проектов.
Только Paper2; никаких новых Native/Paper/V2/V3-контролей. Сравнение прежде всего с Paper2
из серии с лимитами 2 МиБ, проведённой ранее. Это последовательные, не одновременные серии.

## Единственное изменение runtime относительно большого Paper2

| Ограничение | Большой Paper2 | Эта серия |
|---|---:|---:|
| Сериализованное Σ | 2 097 152 байта | 32 768 байт |
| Принимаемый input действия | 2 097 152 байта | 65 536 байт |
| Сохраняемые аргументы действия | 2 097 152 байта | 3 072 байта |
| Сохраняемый результат | 2 097 152 байта | 4 096 байт |

Прежние политики сохранены: превышение Σ/input отклоняется, аргументы получают preview,
результат усекается с маркером (маркер добавляется сверх лимита текста). Исправление history_envelope для защиты JSON от повторной
обрезки СОХРАНЕНО. Это проверка малых лимитов без возврата ошибки сохранения состояния,
а не побитовая копия старой сборки до исправления. Четыре лимита меняются вместе;
их отдельный вклад этим экспериментом не измеряется.

Paper2 остаётся прежним: одно O (действие, аргументы, статус, результат), рекурсивный patch,
та же схема и инструкции Paper, одно действие за шаг, без comment/revision, только finish.
Ограничения инструментов/провайдера не отключаются. 1 КиБ для comment нерелевантен Paper2.

## Условия и предзапусковые проверки

- gpt-5.6-sol и gpt-6-astra, medium reasoning.
- Пять прежних SPEC и тот же one-shot prompt, внешний оценщик без правок.
- Пять повторов, максимум пять основных CLI суммарно, 15 минут на сессию.
- Порядок задач/моделей тот же, что у большого Paper2; новый путь результатов и рабочие папки.
- Глобальные скиллы и инструкции временно перемещаются, затем восстанавливаются.
  Используется исправленное восстановление исчезнувших каталогов и строгий guard.
- Новый active источник, ошибка модели/авторизации/лимита, отсутствие usage или повреждённый
  переход останавливают новые запуски. Таймауты и неудачи задач остаются исходами.
- Отдельная сборка от того же base commit плюс замороженный Paper2 patch и четыре изменения
  констант. Проверяются unit/CLI тесты границ, небольшого O, JSON и finish; сборка, doctor,
  расписание, изоляция и восстановление. Известные недоступные shell fixtures раскрываются.

Старые источники и бинарники не меняются. Manifest фиксируется перед первой модельной сессией.
Полный успех = все проверки + exit 0 + без таймаута + принятый finish. Известная проверка CLI delete
будет выполнена отдельно на копиях всех десяти CLI, без исправления кода и исходного score.
Input включает cached как подмножество, отдельный permission reviewer не включается.
Число обрезок, фактические размеры Σ/O и завершение сохраняются для анализа.
Приватные промпты, рассуждения и вывод инструментов не публикуются.
