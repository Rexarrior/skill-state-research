# Две серии Codex с расширенными лимитами: Astra и Sol

Дополнение для статьи, 2026-09-09. Собраны все 200 завершённых сессий:
по пять повторов пяти проектов в четырёх режимах для каждой модели.
Новых вызовов моделей при подготовке этого пакета не было.

- [Astra: таблицы, повторы, аудит размеров](REPORT-astra.md).
- [Sol: таблицы, повторы, аудит размеров](REPORT-sol.md).
- Протоколы до запуска: [Astra](../codex-astra-large-context-20260908/PROTOCOL.md),
  [Sol](../codex-sol-large-context-20260909/PROTOCOL.md).
- [Patch ядра](../codex-astra-large-context-20260908/kernel.patch) и
  [происхождение общей сборки](../codex-astra-large-context-20260908/build-manifest.json).
- [Предыдущие серии с малыми лимитами](../codex-clean-comparison-20260908/README.md)
  сохранены отдельно и не переписываются.

По 2 MiB выделено на полный state, принимаемый input действия, сохраняемый input
и сохраняемый result. JSON перехода также защищён от вторичной обрезки контейнера.
Это совместное изменение, не отдельная абляция каждого ограничения. Native не
переделан в state; его инструменты и модельное окно не расширялись. Comment —
прежний 1 KiB, окно V2/V3 — k=3. Скиллы и глобальные инструкции временно убирались.

Capture сверил замороженные исходники обеих кампаний и связал счётчики summary
с записями usage. Проекты скопированы без зависимостей, кэшей, симлинков и
потенциально секретных файлов. Сырые контексты, tool output и рассуждения не
экспортируются. Ссылки с `.private` в provenance — только для локальной сверки.

Известная проверка taskboard delete выполнена на отдельных копиях всех 40
CLI-проектов. Она изменила один балл Sol/Native: исходный тест требовал лишнее
поле в ответе. Поэтому полный успех Native в отчёте — 24/25, а в исходном
оценщике — 23/25. Все остальные исходные оценки остались прежними. Исходные
summary не переписывались; обе оценки сохранены явно.

## Проверка и происхождение

Однократные `capture.ts` и `audit-taskboard-delete.ts` адаптированы из предыдущего
пакета, но работают только с новыми сериями и отказываются перезаписывать снимки.
`analyze.ts` строит агрегаты по всем исходам; `verify.ts` независимо сверяет суммы,
повторы, определения успеха и отпечатки. Проверка без вызовов моделей:

```sh
bun experiments/codex-large-context-comparison-20260909/verify.ts
```

[Публичный manifest](publication-manifest.json) фиксирует этот пакет отдельно
от исторических снимков. Не пересоздавать manifest ради устранения несовпадений.
Вспомогательные вызовы permission reviewer здесь не пересчитывались и не входят
в таблицы. Нет новой оценки всех требований, статистического доказательства
причинности или автоматической публикации в GitHub.
